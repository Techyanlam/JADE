# JADE

Jade's spelling revision site.

## Pages

- [index.html](index.html) — hub page, for future links.
- [spelling.html](spelling.html) — **Spelling — English Spelling Words**: all 121 spelling word cards from the school list, 14 September – 11 November, with pictures, dates, search, month filters, and a Hide-the-words self-test mode. Each card also has a speaker button to hear the word. The Spelling page is password-protected.

Published with GitHub Pages at https://techyanlam.github.io/JADE/
